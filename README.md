3. This website is a tool designed for Universitas Gadjah Mada students who are looking for affordable places to eat. With a few simple clicks, students can find recommended restaurants closest to their campus. The website categorizes food options (such as Padang, rice, pizza, etc.) to help eliminate decision fatigue, and clicking on a category displays a brief description of each restaurant.

4. HTML, CSS, JavaScript, Visual Studio Code, and AI assistance.

5. Installation & How to Run the Project:
No additional frameworks, dependencies, or local servers are required to run this project.
- Download or clone this repository to your computer.
- Ensure all project files (`GAMAEATS.html`, `style.css`, `script.js`, and all `.mp3`/`.png` media files) are kept in the same folder.
- Double-click `GAMAEATS.html` (or right-click and select "Open with" any web browser such as Chrome, Opera GX, Edge, or Firefox).
- Make sure you have an active internet connection so external fonts, restaurant images, and Google Maps links load properly.
